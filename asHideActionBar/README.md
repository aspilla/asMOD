# asHideActionBar (Midnight)

Automatically hides action bars.

![sample](https://github.com/aspilla/asMOD/blob/main/.Pictures/asHideActionBar.gif?raw=true)

## Target Frames

You can choose which bars to hide using the following settings:

- Hide Action Bar 1
- Hide Stance Bar
- Hide Pet Bar
- Hide Action Bar 2
- Hide Action Bar 3
- Hide Action Bar 4
- Hide Action Bar 5
- Hide Action Bar 6
- Hide Action Bar 7
- Hide Action Bar 8

## Configuration

Settings can be modified via `ESC` > `Options` > `AddOns` > `asHideActionBar`.

# asHideActionBar (한밤)

액션 바들을 자동 숨김

![sample](https://github.com/aspilla/asMOD/blob/main/.Pictures/asHideActionBar.gif?raw=true)

## 대상 프레임

다음 설정으로 숨김 여부 선택 가능

- 행동 단축바 1 숨김
- 태세바 숨김
- 소환수 바 숨김
- 행동 단축바 2 숨김
- 행동 단축바 3 숨김
- 행동 단축바 4 숨김
- 행동 단축바 5 숨김
- 행동 단축바 6 숨김
- 행동 단축바 7 숨김
- 행동 단축바 8 숨김

## 설정

`ESC` > `설정` > `애드온` > `asHideActionBar` 에서 설정 변경 가능
