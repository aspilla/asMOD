# asPetAlert (Midnight)

Alerts you when your pet is dead or missing.

![asPetAlert](https://media.forgecdn.net/attachments/1698/83/aspetalert-jpg.jpg)

## Features

- Works for Frost Mage (with talent), Unholy Death Knight, Hunter (Marksmanship based on talent), and Warlock (when Grimoire of Sacrifice is not used).
- If your pet is missing, a `No Pet` alert will be displayed in the center of the screen (disabled while flying).
- If your pet dies, a `Pet Dead` alert will be displayed in the center of the screen.
- If your pet is not attacking, during you are under combat, Display a passive skill icon.
  - (Note : Should add 'Pet Passive' spell on the pet spell bar)

## Configuration

- The text and button displayed in the center of the screen can be moved.
- **Move Position**: Enter the `/asConfig` command in the chat window.
- **Reset Position**: Enter the `/asClear` command in the chat window to reset to default settings.

- Settings can be adjusted via **ESC > Options > AddOns > asPetAlert**.
- `Alert Font Size`: Text size (Default: 30).
- `Display button when pet is passive` : (Default: On).

# asPetAlert (한밤)

소환수 죽거나 없으면 알림

![asPetAlert](https://media.forgecdn.net/attachments/1698/83/aspetalert-jpg.jpg)

## 기능

- 냉법(특성), 부정죽기, 사냥꾼 (격냥은 특성), 흑마 (희생 특성 아닌경우) 동작
- 소환수가 없으면 `소환수 없음` 이라고 화면 중앙에 알림 (비행시 알리지 않음)
- 소환수가 죽으면 `소환수 죽음` 이라고 화명 중앙에 알림
- 전투중 소환수가 공격하고 있지 않으면, 소환수 수동적 Icon을 화면 중앙에 표시
  - (참고 : '소환수 수동적` 기술을 소환수 바에 추가 해야 동작)

## 설정

- 화면 중앙에 표시되는 글씨는 이동이 가능합니다.
- **위치 이동** : `/asConfig` 명령어 채팅창에 입력
- **위치 초기화** : `/asClear` 명령어 채팅창에 입력, 기본 설정으로 초기화

- `ESC` > `설정` > `애드온` 탭에서 `asPetAlert`를 찾아 옵션을 변경할 수 있습니다.
- `알림 글씨 크기` 글씨 크기 (기본 30)
- `펫 수동적 버튼 표시` (기본 On)
