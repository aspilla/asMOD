## Features
- **Druid**: Alerts when not in the current specialization's appropriate form.
- **Rogue**: Alerts when in `Stealth`.
- **Warrior**: Alerts when not in the current specialization's appropriate stance.
- **Shadow Priest**: Alerts when not in `Shadowform`.
- **Shaman**: Alerts when in `Ghost Wolf` form.

## Configuration

- The text and buttons displayed in the center of the screen can be moved.
- **Move position**: Type `/asConfig` in the chat window.
- **Reset position**: Type `/asClear` in the chat window to reset to default settings.

- Open `ESC` > `Options` > `AddOns` tab and select `asStanceAlert` to modify options.
- `Show Button Instead of Text` (Default: Off)
- `Alert Text Size` (Default: 30)
- `Alert Button Size` (Default: 40)

## 기능
- **드루이드** : 현 특성 폼이 아닌 경우 알림
- **도적** : `은신`시 알림
- **전사** : 현 특성 태세가 아닌 경우 알림
- **암사** : `암흑 형상`이 아닌 경우 알림
- **주술사** : `늑대폼`인 경우 알림

## 설정

- 화면 중앙에 표시되는 글씨/버튼은 이동이 가능합니다.
- **위치 이동** : `/asConfig` 명령어 채팅창에 입력
- **위치 초기화** : `/asClear` 명령어 채팅창에 입력, 기본 설정으로 초기화

- `ESC` > `설정` > `애드온` 탭에서 `asStanceAlert`를 찾아 옵션을 변경할 수 있습니다.
- `글씨 대신 버튼 표시` (기본 Off)
- `알림 글씨 크기` (기본 30)
- `알림 버튼 크기` (기본 40)
